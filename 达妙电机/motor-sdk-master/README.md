# 电机 SDK

这里集中维护达妙电机二次开发相关 SDK、语言示例和 PC 端 USB2CAN/USB2CANFD 调用示例。

## 目录

- `C#例程/`：基于 USB2CAN 的 C# 调用示例和相关协议资料。
- `C++例程/`：基于 USB2CAN、USB2CANFD 的 C++ 调用示例。
- `Matlab例程/`：Matlab 环境下的电机 SDK 调用示例。
- `Python例程/`：基于 USB2CAN、USB2CANFD 的 Python 调用示例。

## 维护规则

- 和电机 SDK、语言调用、USB2CAN/USB2CANFD 二次开发直接相关的代码放在这里。
- 偏整机、平台或控制流程的案例继续放在 `../电机控制例程/`。
- 模块通信类通用 SDK 继续放在 `../模块通信SDK/`。
