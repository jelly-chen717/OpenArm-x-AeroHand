# MIDI 文件与程序

- 双击 `四指do rei mi fa.cmd`：四音固定循环三轮。
- `玛丽有只小羊羔.mid`：示例曲目。
- `piano_four_config.json`：已标定的四指配置。
- `midi_piano/`：七音 MIDI 规划与模拟程序、示例及独立 Python 环境。

实物播放前断开官方上位机，保持手掌标定位置。停止按钮尝试恢复准备姿态，实际释放需现场确认。

本文件夹仍依赖上一级 `aero-hand-open/sdk/src` 中的官方 SDK，不能单独复制后直接使用。原三指程序与官方上位机保留在上一级。
