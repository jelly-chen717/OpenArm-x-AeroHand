# OpenArm 监视控制台

双击本目录的 `启动监视控制台.cmd`，浏览器打开 [本机控制台](http://127.0.0.1:8091/)。默认使用离线虚拟传输，从 V1 模型初始姿态计算关节与末端坐标。启动脚本使用项目已有的 `openarm/.venv`。

现场联调时，在本目录通过 PowerShell 启动实机模式。

```powershell
& '.\启动监视控制台.cmd' --mode hardware
```

实机服务默认在 [127.0.0.1:8092](http://127.0.0.1:8092/) 监听，启动后查询两条 CAN FD 通道的反馈。默认左臂 `0x51`、右臂 `0x52`，可用 `--left-channel` 和 `--right-channel` 指定。现有实机配置使用 MIT。首次使能要求两臂在线、静止且失能。工作线程会核对参与电机的模式、协议量程和起姿。

## 顶部的电机控制

双臂静止并回读 14 轴失能后，从顶部“电机模式”选择模式，选择立即生效，旧预览失效。实机配置支持切换时，等待逐轴回读成功。运动面板的“关节控制 / IK 控制”选择目标的输入方式。

| 电机模式 | 位置目标如何执行 |
| --- | --- |
| MIT · 阻抗 | 发送位置、速度和关节增益。到位后持续发送目标角和零目标速度。 |
| POS_VEL · 位置速度 | 发送轨迹位置与正的速度上限，由驱动器闭合位置环。 |
| VEL · 速度 | 控制台根据轨迹速度和角度误差计算限幅速度。到位后外环继续纠正偏差。 |
| POS_FORCE · 力位混合 | 发送位置、速度上限和电流标幺上限。离线编码使用 10%，实机值来自现场协议配置。 |

点击“全部使能”后，左右 J1～J7 以各自当前角度进入保持。顶部计数来自关节反馈，14/14 表示两臂都已确认使能。“全部使能”也可跳过，直接执行预览会使能有位移的轴。离线使用理想空载模型，可检查控制帧和操作流程，带载精度与电流响应需要实测。

## 操作

1. 选择关节控制或 IK，以及左臂、右臂或双臂。关节目标使用标定零点和当前逻辑方向。填写希望调整的关节，留空跳过该轴。IK 使用基座系毫米坐标和当前手腕朝向，可把当前坐标填入表单再作调整。离线模式支持 Aero 固定手指模型的指尖，实机 IK 使用 J7 手腕控制点。
2. 设定运动时间和额定速度百分比，预览目标。网页按各关节的标定角度范围规划，执行器根据本次起点和目标计算各轴行程。速度百分比基于参与轴中最低的额定速度，轨迹加速度上限为 1 rad/s²。实机路径按 V1 原装夹爪几何检查接触。
3. 对照预览的角度和指令轴，在 60 秒内单击执行。执行前复核两臂起姿。终点误差通过 0.015 rad 判据后，页面显示“已到位 · 使能保持中”。同一页面可继续预览和执行已使能轴的新目标，其余已使能轴维持原目标。需要增加参与轴时，先停止，再选择全部使能。
4. 点击“停止并失能”，等待使能计数回到 0/14 后可以切换模式。操控页失联超过 3 秒、运行故障或服务正常关闭都会触发停止。实机停止会核对两臂失能回读，回读失败显示“停止未确认”。

## 实机多模式的接入条件

项目内已有左右 J2、J6 的历史固件回读。完整 14 轴 C02 盘点、对应固件的特殊帧地址及失能时预装当前位置的行为仍待现场确认。C02 的备份命令与现场顺序见[位置模式切换方案](../docs/project/OpenArm14关节位置模式切换方案_20261117.md)。

现场核验完成后，原启动脚本支持附加 `--mode hardware --drive-profile <现场协议配置.json>`。配置使用 UTF-8 JSON，包含以下字段。

| 字段 | 内容 |
| --- | --- |
| `inventory` | 完整 C02 备份 JSON 的路径，可相对协议配置文件。程序检查映射、两臂通道、14 轴身份、寄存器和失能记录。 |
| `special_frame_address` | 对象含 `left`、`right` 两个数组，各按 J1～J7 填写经核实的 `base` 或 `mode`，分别指基础 ID 或模式偏移 ID。 |
| `disabled_preload_verified`、`volatile_mode_write_verified` | 两项均为布尔值。现场确认 14 轴能够在失能时预装当前目标、模式寄存器写入可易失生效后填 true。 |
| `pos_force_current_fraction` | 已核实适用于双臂的最大相电流比例，范围 0.0001～1。 |

带协议配置启动后，先在失能状态选择模式。服务核对各轴硬件、软件和子版本，逐轴写入需要变化的 CTRL_MODE，独立读取全部 14 轴后开放使能。部分写入失败时按原值回退已尝试的轴，页面保留故障并锁定执行。网页切换流程不发 Flash 保存命令。再次连接后应重新确认模式。

## 反馈与日志

- 关节表可切换角度、速度、力矩、温度与电机状态。反馈过期时对应关节显示空值。实机手腕坐标由 CAN 关节回读经 V1 正运动学换算。
- 重要反馈区显示进度、到位、取消、故障和跟踪偏差。运动中的偏差逐周期记录，轨迹结束时按终点误差判断到位。执行日志可按等级筛选，按事件、参数或指令编号搜索。
- “导出 JSONL”下载当前服务会话的完整日志，包含控制参数、逐周期目标、观测、偏差和停止回读。原始文件保存在 `logs/openarm/monitor`。每条记录带有 `mode`，同一条指令用 `request_id` 关联。

WEB04 的四种模式已完成离线浏览器验证。实机协议分支通过替身 CAN 测试。WEB03 历史实机记录覆盖反馈和失能，WEB04 的实物模式切换、14 轴使能和带载保持待验收。
