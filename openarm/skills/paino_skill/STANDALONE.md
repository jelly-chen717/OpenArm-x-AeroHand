# 独立 HTML 演奏

双击 `piano_standalone.html`，用 Chrome 或 Edge 打开。只需这个文件，无需 Python、MuJoCo、8089 或 8090；可以复制到另一台电脑离线使用。

1. 下拉选择内置歌曲，或点击“导入 TXT”选择一份或多份 UTF-8 乐谱。
2. 点击“开始演奏”，首次播放会解码本曲所需的钢琴采样。
3. 观看琴键高亮、音符和同一水平线上的双手位置；“结束演奏”立即停止声音。
4. 自然结束或手动结束后，点击“完成演奏”返回选歌，可再次演奏。

页面空白处键入 `config` 可编辑临时谱和调度容差。临时谱、导入文件与参数仅保留在当前页面会话。切换到后台会停止播放，防止回到页面时集中补播。

固定四指模式：左手 1234、右手 789x。白键从 A0 到 C8 编号 1–52；左手 index 1–20，右手 index 24–49。每个 index 表示四指覆盖最左白键。移臂命令仅改变示意手位，不控制机器人；音符由谱面的 index 和手指映射直接触发，不依赖物理接触。

播放前严格校验整份 TXT：未知指令、时间、范围、移臂冲突、重复按下、未释放等；时间用整数微秒解析，音频以 AudioContext 绝对时间调度。不执行文本代码，不做 IK、速度、加速度或碰撞预检。

HTML 内嵌构建时 `music_data` 直属 TXT 和 52 个白键原始 WAV 采样。单个 HTML 体积较大是因为保留原采样。浏览器不能自动扫描磁盘文件夹；以后增加歌曲可直接导入，或重新构建：

```
.venv\Scripts\python.exe skills\paino_skill\build_standalone.py
```

备用短谱“四指试听”适合先检查声音。遇到格式错误，页面显示具体行号；原目录中的非乐谱 TXT 也会保留在歌单中，选中播放时严格拒绝。

现场检查：提前打开文件并试听；确认系统音量和输出设备；演奏期间保持页面在前台；停止、返回选歌后再次播放确认流程。

维护源文件：`web/standalone.html`（独立页面模板）、`build_standalone.py`（打包）。原 8090 服务与页面保持独立。
