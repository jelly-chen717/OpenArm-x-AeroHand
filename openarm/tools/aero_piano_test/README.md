# Aero 右手钢琴击键测试

参考飞特测试窗口的“抬起/按下、单指、全部、随机、轮流”操作流程。
这是独立实机工具，不接入 8089、8090、MuJoCo 或机械臂。使用项目环境中
`aero-open-sdk==0.1.0.dev1`。连接和动作必须在窗口里手动触发。

## 启动

双击项目根目录 `start_aero_piano_test.cmd`，或在项目 PowerShell 中执行：

```powershell
.\start_aero_piano_test.cmd
```

仅体验界面、不连接设备：

```powershell
.\start_aero_piano_test.cmd --demo
```

## 首次测试

1. 在官方 GUI 中 Disconnect，释放 COM8。保留已经完成的标定。
2. 固定手腕，保证手指的小幅动作有空间；选择 COM8，点击“连接 / 只读反馈”。
3. 确认反馈更新，再勾选“允许手指动作”。连接不自动归零、不自动张手。
4. 首先只测试食指。用 ±1° 小幅调整至合适的悬停姿态，点击“记抬起”。
5. 继续小幅调整到能稳定按响琴键的位置，点击“记按下”。触底后不要继续加大角度。
6. 先用该行“抬起 / 按下”复核两个位置，再选择循环模式和次数，点击开始。
7. 逐指完成实物标定后，可选择多指同时、随机组合或逐指轮流测试。

初始抬起、按下字段为空，不提供未经实测的默认动作角度。配置在本目录
`config.json` 自动保存（启动动作、记录位置、关闭窗口时），也可手动保存。
演示配置单独保存在 `demo_config.json`，不会污染实机配置。

## 与飞特测试的差异

- 首版控制食指、中指、无名指、小指，拇指三个耦合通道保持本次动作开始时的驱动位置。
- 使用官方 SDK 的 7 维紧凑关节表示中的四指角度，单位为度，范围 0–90。
  官方腱模型负责映射。界面估算角度来自驱动反馈，不是每个关节的独立测量。
  这些范围是 SDK 输入范围，不是琴键接触下的安全行程。
- 未选择通道保留动作开始时读到的原始驱动计数。整包位置命令仍包含七个通道，
  因此“保持”是位置目标保持，不代表断力矩，也不代表机械结构完全没有耦合。
- 每指“过渡时间”控制目标插值，越大越慢，默认 0.5 秒；不是驱动速度百分比，
  也不是实测运动用时。程序不改电机速度、力矩、电流限制、ID 或校准参数。
- 可一键将所选手指切换为 0.05 秒快速过渡，或 0 秒直接目标。0 秒时每段只
  发送一次终点，不做软件插值、不额外等待；实际动作仍受驱动和机构限制。
  切换仅改变所选手指过渡时间，不改已经记录的位置，也不自动触发动作。
  直接目标模式至少保留一段非零停留时间；过短停留可能在手指到位前就反向。
- 按下和抬起停留时间从该段目标发送完毕开始计算，默认各 0.3 秒，可为 0。
  完整周期还包含按下和抬起两段过渡，以及串口反馈耗时。
- 快速连续动作共享约 5 Hz 的反馈检查，不再每次按下/抬起都重复读取四组反馈。
  每个新任务仍先读取反馈；超时和故障锁定保持有效。非零过渡按最高约 100 Hz
  插值，0 秒直接目标不受插值周期限制。这不是实时系统的节拍保证。
- “逐指轮流”每次按下一指再抬起计为一次循环，不是遍历四指才计一次。
- 只记录指令循环，不判断实际发声。循环日志在 `logs/aero_piano_test/`，
  包含配置、完成的循环、停止/异常事件。GUI 显示七通道位置、电流、温度和转速。

## 停止与故障

- “停止并抬起”：中断当前任务，向本次参与且已设置抬起值的手指发送抬起目标。
  正在循环时所有所选手指均有抬起值。未设置抬起位置的微调动作只停止后续发送。
- “立即中止发送”：不再发新目标，包括抬起目标；需要重新连接后继续。
- 串口超时、反馈无效或明显调度延迟会中断并锁定动作，不补发，不盲目发送抬起。
- 关闭窗口/断开连接不发送新位置，不代表驱动停止保持或手指已经松开。
- 上述软件停止不能替代手边的物理断电手段，尤其是通讯中断或机械卡住时。

初版没有按键力传感器、接触检测、自动发声识别或限流保护配置。请结合实物、
音频或电子琴 MIDI 统计漏音/误触；仅看循环计数不能判断弹琴成功率。
