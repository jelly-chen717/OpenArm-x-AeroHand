# Aero 双手 TXT 指法排练

独立入口：项目根目录 `start_aero_score_controller.cmd`。
只控制 Aero Hand 的食指、中指、无名指、小指，不连接机械臂，不启动或调用
8089、8090、8769，也不加载 IK/MuJoCo。原仿真入口保持原用途。

OpenArm 实琴音域为 C2–C7，双手食指原位为左 B3、右 B4。固定手腕排练时，实际落键取决于现场手位。[实琴编号与标定表](../../../monitor-ui/README.md#实琴琴键与食指原位)

## 当前接法：右手实机 + 左手软件模拟

也可以直接双击 `start_aero_score_right_real.cmd`。这个专用入口每次启动都重新
读取原右手测试窗口保存的角度和串口，设为右手实机、左手模拟，不自动连接或运动。
这样即使旧窗口关闭时保存了“双手模拟”，新启动仍会选中右手实机。
左手模拟若误记成按下/抬起相同，则恢复为模拟专用的 0°/20°；左手实机位置保持独立。

1. 停止原右手测试窗口的动作，抬起手指并断开 COM8；官方 GUI 也要释放该端口。
2. 双击 `start_aero_score_controller.cmd`。启动不自动连接、不自动动作。
3. 左手保留“软件模拟”勾选，点击连接。模拟直接在程序内运行，不需要 COM1。
4. 右手取消“软件模拟”，端口设为 COM8，点击连接；取得反馈后确认已归零并固定。
5. 分别打开“左手位置标定”“右手位置标定”，检查抬起/按下角度，点击“抬起已配置手指”。
6. 回到 TXT 乐谱，先载入“双手短测试”，检查整谱，再点“开始指法排练”。

左手还没有硬件，因此左手显示和记录都标为模拟，不能用来证明真实左手的性能。
COM1 这个端口名称本身不能代替一只手。若使用虚拟串口，另一端还必须完整模拟
Aero 协议和反馈；当前实现不需要这层虚拟串口。

仅用软件验证两手：

```powershell
.\start_aero_score_controller.cmd --demo
```

`--demo` 使用独立的 `demo_config.json`，两手均不会打开串口。

## 接入真实左手

先停止，断开左手模拟连接，取消左手“软件模拟”，填写真实左手串口。
左右手不能使用同一个真实 COM 口。通过官方工具完成左手归零后，再连接本窗口，
确认已归零并固定，逐指微调、记录左手抬起/按下位置。

模拟与实机位置分别保存。左手实机位置初始为空，不从右手或模拟配置复制。
右手实机位置首次启动时从 `tools/aero_piano_test/config.json` 复制，此后各自独立保存，
不会反向修改原右手测试窗口配置。切换模式或重新连接会清除“已归零并固定”的确认。

## 乐谱语义

严格复用现有 `paino_skill.score.parse_score(..., finger_count=4)`，不执行文本中的代码。

| 谱符 | 左手 | 谱符 | 右手 |
| --- | --- | --- | --- |
| 1 | 小指 | 7 | 食指 |
| 2 | 无名指 | 8 | 中指 |
| 3 | 中指 | 9 | 无名指 |
| 4 | 食指 | x | 小指 |

- `hand(D,...)` 发送已标定的按下目标；`hand(U,...)` 发送抬起目标。
- 不插入过渡、0.1 秒停留或自动抬起，不做速度缩放。抬起由原谱 U 决定。
- `sleep` 决定原谱时间；整数微秒表示不改变 Windows 非实时系统的性质。
- `left_arm_move` / `right_arm_move` 仅由共享解析器校验原谱索引、移动结束时间及冲突，
  **不产生任何机械臂动作**。界面显示忽略条数。保持原谱总时长，包括尾部移动的截止时间。
- 固定手腕时，变化的 `index` 不会改变真实手指所在键位。这只是指法/节奏排练，
  不代表能弹出原谱音高。若手位变化是正确发声的前提，需要后续机械臂阶段解决。
- 同一时刻同一手的不同手指变化合并为一个位置包。零时间内对同指先按后抬会在预检时拒绝。
- 五指谱仍不执行。两只手的拇指三个通道和未参与手指保持准备阶段的驱动位置计数。

## 调度、准备和停止

两手各用一条工作线程拥有自己的串口，独立收发。两手准备完成后，约定共同的
单调时钟起点；串口实际发送仍有偏差，日志记录计划时刻与实际发送开始/完成时刻。
开始前会检查参与手指是否已经位于抬起姿态；默认容差 2° 是 SDK 估算关节角的
软件检查阈值，可在窗口修改，不代表实物指尖精度或到位保证。准备检查不发送动作。

运行时仅查询位置，约 5 Hz；避免在临近动作时进行阻塞读取，但位置反馈不得长期过期。
空闲时读取官方 SDK 的位置、电流、温度、转速反馈。界面主要显示估算关节角。
不设置电机速度、力矩、电流限值、ID，不执行 Homing，也不发送 CAN。

- 迟到超过 50 ms、错过多个不同动作时刻或通信异常，停止后续指令，不集中补发或延长谱时。
- 任一执行手故障会通知另一手停止；通信正常的已执行手发送抬起目标。
- “停止并抬起”中断排练；故障连接无法保证抬起成功，错误会记录。
- “立即中止发送”和关闭窗口不再发送抬起目标，驱动可能保持最后指令。
- 软件停止不是断电开关；不提供中途续奏，重启排练必须重新检查。

正常结束由谱末 U 完成释放。日志位于 `logs/aero_score/`，JSON 保存谱文本、模式、
角度配置、结果和事件；CSV 保存每手的发送时间、谱行和动作。`demo` 字段明确区分
模拟/真实通道。日志表示指令执行，不等于实际接触、正确音高或成功发声。


测试使用软件模拟、可控时钟和替身串口，覆盖双手谱映射、同刻合并、迟到停止、
