# Aero Hand Open 上位机

双击工作区根目录的 [03-Aero Hand 调试.cmd](<../../03-Aero Hand 调试.cmd>) 启动官方图形界面。

软件来自本地官方仓库 `aero-hand-open/sdk`，安装版本为 0.1.0.dev1。
独立 Python 环境位于 `.venv-aero`，请保留此目录。

## 连接机械手

1. 按硬件说明连接舵机电源和 USB；USB 不代替舵机电源。
2. 在界面选择对应 COM 口，波特率使用 921600。
3. 点击 Connect 连接。未连接硬件时可以打开界面。
4. 归零、校准和滑块操作会驱动机械手，首次使用请按官方说明进行。

官方使用说明：aero-hand-open/sdk/README.md
固件及校准说明：aero-hand-open/firmware/README.md

此软件用于配置与调试；MIDI 弹琴需要另行开发控制程序。
