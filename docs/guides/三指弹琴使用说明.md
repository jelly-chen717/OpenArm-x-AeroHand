# 三指固定键循环程序

食指 do → 复位 → 中指 re → 复位 → 无名指 mi → 复位，重复运行。默认每音 0.5 秒，每轮 1.5 秒；单指试弹时只重复选中的手指。程序不自动寻找琴键，不读取 MIDI，不执行归零或硬件校准。

## 当前可以直接做的事


位置补齐后选 2 实际试弹 3 轮；选 3 持续运行。在控制台按 Ctrl+C 停止，并尝试平滑回到配置的准备姿态。第二次 Ctrl+C 可中断复位。关闭窗口、拔线或断电无法保证软件复位成功。

## 稍后需要填写的配置

在工作区中编辑 `apps/fixed_position/piano_config.json`：

- `port`：上位机使用的串口，例如 `"COM5"`。
- `rest_pose`：整只手的七通道准备姿态；食指、中指、无名指填写释放琴键时的角度。拇指三通道、小指填写希望保持的角度。
- `press`：食指、中指、无名指各自能触发琴键的角度。

`null` 表示待提供的未知量，实际运行前必须替换为数字。不能写成带引号的数字。角度单位为度，使用官方 SDK 七维关节角度模式，与本地官方上位机调用的关节位置接口一致。

七通道依次为：拇指外展、拇指屈曲、拇指联动屈曲、食指、中指、无名指、小指。后三指等非拇指通道各用一个角度，由 SDK 展开为该手指的三个关节目标；它们不是三节关节能分别独立控制的含义。不要填入电机角度、滑块百分比或腱绳长度。界面字段对应关系不明确时，保留 null，待核对截图。

准备姿态不必是全零，也不必完全张开。按下值与复位值必须不同，按压方向以实物调试为准。实际运行要求所有位置填写完整，即使只试弹一根手指。

## 命令行

在本目录 PowerShell 中运行：

```powershell
# 模拟三轮，不连接机械手
.\.venv-aero\Scripts\python.exe .\apps\fixed_position\piano_player.py

# 食指实际试弹五次
.\.venv-aero\Scripts\python.exe .\apps\fixed_position\piano_player.py --run --finger index --cycles 5

# 三指实际循环三轮
.\.venv-aero\Scripts\python.exe .\apps\fixed_position\piano_player.py --run --cycles 3

# 三指持续循环，Ctrl+C 停止
.\.venv-aero\Scripts\python.exe .\apps\fixed_position\piano_player.py --run --cycles 0
```

中指使用 `--finger middle`，无名指使用 `--finger ring`。没有 `--run` 时始终为模拟。

## 节奏参数

`down_seconds` 按下 0.12 秒；`hold_seconds` 保持 0.18 秒；`up_seconds` 复位 0.15 秒；`gap_seconds` 间隔 0.05 秒。四项之和就是每个音的周期，mi 到下一轮 do 也相同。`startup_seconds` 是进入准备姿态的过渡时间，`stop_seconds` 是停止后的复位时间。`update_hz` 是位置指令更新频率，并非弹奏频率。

程序用单调时钟调度和缓入缓出的插值发送位置。若系统或通信变慢，保留释放间隔并放慢节奏，不会补发一串快速按键追赶时间。Windows 与机械手都不是严格实时系统，实际发声间隔需实物验证。

## 实际运行流程与边界

先在上位机确认位置，固定手掌，再断开上位机连接以释放串口。程序检查参数、转换角度后连接串口，读取当前电机位置；只有读到有效响应才开始过渡到准备姿态。每个按键动作只改变目标手指，其他通道维持配置的准备姿态。

先逐指试弹，再试弹三轮，最后持续循环。位置指令写入失败会停止循环并尝试复位；串口中断时复位可能失败，需要手动处理。发送成功只代表串口接收了数据，不代表琴键实际压下或释放。本程序没有触键力控制、声音检测或琴键行程反馈，也不修改固件的速度、电流或力矩设置。

现阶段只进行模拟与自动测试，未连接实物执行本程序。
