# 14 轴模型对应与环境核对

日期：2026-11-15。阶段：A01、A05。仅离线加载和数值核对，未打开 CAN 总线。

## 结果

rc1 已安装 V1 模型定义与当前官方 MuJoCo V1 scene 的 14 个臂关节在各自 link0 坐标系中一致：关节轴、父子关系、固定位置/旋转、零参考和限位均通过。软件模型之间的候选映射为 `q_mujoco = q_ros`；这是模型对比结果，不是当前实机标定验收。

逐臂检查零姿态、中间姿态、14 个单轴正负扰动和 17 个固定随机种子的姿态，共 33 姿态×7 连杆×2 臂=462 个连杆姿态比较。零姿态仅用于离线坐标检查，不代表可执行姿态。

本机无 xacro 包；本次根据读取的 Xacro 宏和 YAML 显式计算七轴固定变换及限位，与加载后的 MuJoCo 数值比较，没有声称完成完整 ROS Xacro 展开或 ROS 运行验收。检查脚本对使用的源公式设有断言，源文件摘要见 JSON。
