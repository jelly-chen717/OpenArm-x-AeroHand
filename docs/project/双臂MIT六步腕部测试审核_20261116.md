## 为什么此前出现模型接触

此前“左右J5同为−88°”的候选把同号角度当成了双侧朝外。当前J5定义为俯视顺时针为正，两臂同号旋转并不镜像：第2步两侧J7+88°后，左TCP相对J7轴横向偏移+189.48mm（外侧），右+189.09mm（内侧）。右夹爪随后回转时扫过中间立柱。

用户明确“左逆右顺”后，第1步改为左J5−88°/右J5+88°。模型第2步末横向偏移变为左+189.48mm、右−188.87mm，两侧都朝外。第三步回零时从外侧转向前方，不再经过中柱。**最新全路径6007采样点未检测到模型接触**；没有为此改全局映射或扩大机械限位。

J7“正向向前”指参考姿态下的关节方向；J5先转动会改变腕部局部轴在世界坐标中的朝向，因此不可把它当作任意姿态下沿世界正前方直线移动。前视对比图：`logs/openarm/sync/dual_wrist_sequence_20261116/outward_direction_comparison.png`。方向数值：同目录 `direction_geometry_audit.json`。

此前同号方案的模型接触并非实机碰撞，也并非仅凭粗碰撞盒猜测：右夹爪实际视觉三角网格与中央立柱视觉网格相交。该证据保存在 `confirmed_zero_return0/collision_geometry_review.json` 与 `collision_review.png`，用于解释已弃用的同号方案。此前−85°/+30°减幅建议同样已被本次保持88°幅度的镜像方案取代。
