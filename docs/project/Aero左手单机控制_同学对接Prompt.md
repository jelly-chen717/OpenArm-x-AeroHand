# Aero 左手单机控制 · 可直接转发的 Prompt

请协助现场同学完成 Aero Hand Open 左手的首次单机调试，交付可复用的左手端口、四指标定和验证记录。左手已安装在 OpenArm 腕部。本轮由手侧同学负责串口和手指，机械臂由臂侧同学负责保持静止并确认腕部支撑。运动由现场同学在窗口手动触发。本轮无需启动 OpenArm 服务、连接 CAN 或播放乐谱。

## 现场怎么做

1. 在 Windows 设备管理器辨认左手控制板的实际 COM 口，关闭占用该口的其他窗口。项目初始左手为模拟，COM1 为占位，COM8 是右手预设。以现场辨认结果填写左手端口。
2. 双击上表启动脚本，在**左手**行取消“软件模拟（不打开串口）”，点“连接 / 只读”。右手保持断开。记录端口、连接结果和初始反馈。若读数缺失或设备身份不清，停在这一步。
3. 与现场同学核实左手已完成归零、已固定且有活动净空，再勾选“实机已归零并固定”。该勾选只是现场确认。归零状态未知时，先向设备负责人核实。
4. 在左手页逐指用 ±1° 微调，每次只动一指。核对通道 3 食指、4 中指、5 无名指、6 小指的实际动作与方向，拇指保持连接时的位置。以安装后的实物确定合适姿态，分别点“记抬起”和“记按下”，完成后点“保存配置”。这里的“按下”可先记录自由空间试验位置；是否能压响琴键留到臂手联调时验证。
5. 逐指点击“按下”和“抬起”，观察目标手指、其他手指与线束，记录目标、反馈及目视结果。指动错、姿态异常或通信超时时立即中止发送并记录。中止后驱动可能保持末目标；断链后由现场人员确认实物姿态。
6. 正常结束时抬起已标定手指，观察并记录末姿态，断开左手，释放串口后交给臂侧同学。
