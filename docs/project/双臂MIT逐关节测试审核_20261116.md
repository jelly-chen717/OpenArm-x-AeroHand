- 40ms周期，最大调度迟到80ms；控制器跳过过期时隙，不密集补发旧指令。只读测得原14轴“读模式+反馈”中位45.85ms、最大48.43ms；批量发送所需的14轴反馈采集中位23.22ms、最大24.73ms。实际带使能的发送周期仍待本次实测。
- 同名左右轴紧邻发送，所有目标先整批校验，再发完14帧并采集反馈。日志记录每对主机发送时间差、发送跨度和采集时长；这不是设备级同一时刻到达保证。批量模式依赖进入和使能时已验证MIT模式、执行期间总线独占。
- MIT前馈力矩为0；内部控制近似为 `τ = Kp(q目标−q实测) + Kd(v目标−v实测)`。3/9/20N·m为**反馈超限停止阈值，不是已设置的固件硬限流**。模型估算不能当成实际输出力矩，真实速度、力矩、误差在运行中逐周期记录；超限、反馈异常或取消均停止并失能，不自动重试或放宽阈值。

## 速度、时间与方向依据

每段采用静止到静止的五次插值 `s(u)=10u³−15u⁴+6u⁵`。峰速 `1.875|Δq|/T`，峰加速度 `(10/√3)|Δq|/T²`；7段峰加速度依次为2.362、2.099、2.015、0.840、2.015、1.400、1.400rad/s²。规划上限取1.0rad/s、2.5rad/s²，均覆盖所列轨迹且低于逐轴额定速度。这是便于观察、结合当前模型与40ms周期选择的快速候选，不宣称未标定负载条件下的数学最短时间。

采用 `hardware-unified-forward-inward-v2-20261116`。原始电机增量左/右依次为：J7 +15/−15°，J6 +30/−30°，J5 +45/+45°，J4 +3/+3°，J3 −45/−45°，J2 −45/+45°，J1 +45/−45°。这些原始符号差异由映射负责，用户操作表始终用统一逻辑方向。

方向描述以机器人坐标为准；当前起点带少量偏角，运动可能同时有其他空间方向分量。随后上游关节运动会改变已完成末端的世界位置和朝向；保持的是各关节角。

## 授权后的唯一执行路径

1. 收到用户对本表的实机运动授权；仅确认新零点不等于运动授权。
2. 只读核对总线独占、14轴在线失能和本次固定零点；任一轴与审核零点差>0.01rad（约0.573°）则拒绝，不能悄悄重设起点。
3. 仅刷新请求ID和有效期，保留审核角度、增益、时长、零点及限幅，另存`request.authorized.json`，先专用入口`--action preflight`通过再执行。
4. 专用入口使用`--mode hardware --action execute --sequence --allow-dual-arm --batch-mit --hold-after --joint-settings ... --left-channel 0x51 --right-channel 0x52 --confirm-bus-ownership --period 0.04 --max-lateness 0.08 --max-error 0.08726646259971647 --cancel-file .../cancel.stop`。本轮未运行此命令。
5. 正常进入`HOLDING_TARGET`后核对14轴使能、位置、速度、力矩及持续反馈，记录PID和停止入口。明确停止时创建本轮`cancel.stop`并等待失能读回；现场物理急停仍可用。取消文件预先存在时禁止使能。
