## 2. 选择的模式与协议边界

目标采用 **POS_VEL，CTRL_MODE=2**，即电机内部位置—速度—电流串级闭环。它适合先验证空中定位，再评估落指精度；并非已经确认能达到毫米精度。MIT为1，VEL为3，POS_FORCE为4；本轮不切VEL或POS_FORCE。

协议核查结果：

- 模式寄存器RID=10（0x0A），模式值为uint32小端；参数通道0x7FF。读操作0x33，写操作0x55，数据含基础电机ID、RID与4字节值。写入返回成功不等于电机切换成功，必须独立读回。
- POS_VEL目标用基础ID+0x100，8字节为两个小端float32：位置rad、最大速度rad/s。速度用正的幅值；方向由目标位置决定，不把MIT的有符号速度前馈原样复制。
- MIT的kp/kd/力矩前馈不在POS_VEL目标帧内；位置环、速度环及加减速参数属于固件参数。现有MIT增益不可作为串级环增益搬用。
- 反馈仍需按现场P_MAX/V_MAX/T_MAX解析；目标float编码不等于实际测量分辨率或定位精度提高。

**协议待核实项必须先解决：** 本地OpenArm CAN参考的使能/失能特殊帧发往基础ID，而达妙u2canfd SDK按当前模式偏移发送特殊命令。不能把两套实现拼接，也不能盲发两个地址试错。接机前按每轴固件适用手册明确特殊帧地址、失能后目标是否可预装载、使能时是否沿用旧目标、模式是否立即生效及是否自动持久化。没有确认就停在只读阶段。旧版手册描述经典CAN，不可据此把当前CAN FD传输改成经典CAN；保持现有传输，确认固件兼容性。

## 3. 接机前的软件准备

2026-11-18 已写入双臂 14 轴的 [POS_VEL 目标配置](../../configs/openarm_position_mode.json)，并实现离线校验及 [C02 只读盘点](../../apps/openarm_position_mode.py)。现场切换结果以同一轴的模式回读和重启核验为准。

```powershell
& 'openarm/.venv/Scripts/python.exe' -B 'apps/openarm_position_mode.py'
# 在完成现有 CAN 控制台交接后，使用新文件名保存只读盘点结果。
& 'openarm/.venv/Scripts/python.exe' -B 'apps/openarm_position_mode.py' --inventory 'logs/openarm/mode_switch/inventory.json'
```

当前 `apps/openarm_driver.py` 的enable_motor明确要求模式1并发送MIT保持帧；command_mit也强制模式1。因此只修改电机寄存器会使当前执行链拒绝运行，绕过检查则会形成错误协议。

模式维护入口的后续写入功能与 POS_VEL 执行分支，复用总线独占、映射、反馈与日志，不修改纯仿真入口或vendor。完整切换链路必须包含：

1. 只读盘点、参数备份、模式写入及逐轴读回、按模式使能/失能、POS_VEL编码和回退；默认只读，写入与使能分开。
2. 每轴模式状态独立保存；任何未知模式、写入超时、部分成功均阻止整臂执行。参数回复与状态回复分流，禁止旧缓存充当确认。
3. 保留 `hardware-unified-forward-inward-v2-20261116` 映射与机械限位。由逻辑角度逆映射到电机原始角度；速度上限按比例绝对值换算。保留既有物理零位和1:1比例，不执行0xFE、不寻挡块、不升级固件、不改ID/波特率。
4. 软件反馈力矩阈值不是电机内部电流硬限制。盘点固件电流限制、过载保护和通信超时；若需修改，形成单独参数差异表，确认单位与作用后实施。禁止将额定力矩数字直接填入电流寄存器。
5. 停止时取消未来目标；故障不自动重连使能或自动恢复运动。可靠性验收覆盖失联后的本机保护和独立急停。
6. 离线测试覆盖14轴地址、float编码、NaN/越界、方向换算、错误模式、部分切换、陈旧回复、回退、取消与断链。虚拟总线通过后才能进入现场；不是本次已通过的测试。

## 4. 现场分阶段实施

### C02：只读盘点和备份

机械臂远离琴键，可靠支撑重力负载，检查线材及急停；停止旧MIT控制器并确认每总线只有一个拥有者。对照铭牌和物理连线确认14轴身份；读取实际使能状态、模式、固件信息（可读项）、ID、量程、电流/速度环/位置环/加减速参数、超时及温度。不能读取的项目用适用工具导出并注明缺项。保存原始CAN回复与逐轴JSON，不依靠历史日志判断当前状态。

通过条件：14/14身份与路由明确，参数可追溯，固件支持模式2及停止流程已确认。发现某轴不是MIT，记录实际值，不自动覆盖。

### C03：单轴失能切换与当前位置保持

先选受支撑、空间充足的一侧J7，另一侧及其他轴保持安全受支撑状态。此阶段不要求整臂同时使能。

顺序：停发旧目标 → 机械支撑 → 目标轴失能并新鲜回读state=0 → 备份 → 写CTRL_MODE=2 → 独立回读=2 → 获取当前原始位置 → 以该位置建立首个保持目标 → 按已核实固件顺序装载目标和使能 → 新鲜回读state=1 → 低速当前位置保持。

若固件无法保证首目标接管前不执行旧目标，暂不使能，先解决启动语义。禁止首目标默认为0；禁止带载在线从MIT热切换。正常试验后先支撑再失能，记录结果；不自动启动下一轴。

### C04：单轴小幅往返与三类电机验证

建议候选：当前位置±1°往返，速度上限0.05rad/s，移动段至少2秒、到位停留2秒、重复10次，最后保持30秒。这些是待现场复算的初始参数，不是下发指令；临近限位只选择可行方向。加减速和停止阈值按固件能力、支撑状态和实测噪声确定后写入最终表。

依次验证J7（4310）、J4（4340）、J3（4340P）、J2/J1（8009P）；随后补齐每侧J5/J6和所有尚未验证轴。每轴记录目标/反馈、稳态误差、超调、到位时间、往返差、温度、力矩及通信时序。此前腕部速度反馈与位置差分有比例差异，须分别记录并核实，不能仅据旧速度解码设定通过结论。

建议初始关节稳态误差门槛≤0.2°，连续稳定1秒；保持无增长振荡。此为待评审工程指标，不是厂家保证，也不是末端验收。达不到就分析内部环参数和负载，不自动提高电流或放宽判据。

### C05：整臂及双臂14轴切换

各轴验证后再按逐轴事务切换，保存成功/失败清单；全部14轴模式读回2才开放双臂POS_VEL执行。先单臂静态保持，再单臂短轨迹，最后双臂同步及至少60秒保持。混合模式只允许受控的单轴调试，不开放整臂任务。

位置模式内部可能各自生成梯形轨迹，同时发送终点不保证各轴同步到位。先测定周期与内部轨迹响应，再选择公共时间轴的平滑中间目标或经验证的同步分段策略，并检查中间姿态和碰撞。不能直接把MIT轨迹速度列当POS_VEL速度上限。

动作规划先确定中轴镜像关系与时间参数；最后确认起姿并采集本次相对测试基准，复算绝对目标、碰撞和限幅，形成最终执行表。相对测试记零不改电机固件零位。旧实验授权与旧请求不复用。

### C06：面向弹钢琴的末端验收

定义实际指尖TCP、手指姿态、负载和琴键坐标系；在琴键上方无接触点进行外部测量。先选每手至少5个代表点，每点同向和反向到达各10次；保存三维偏差、最大偏差、重复定位散布和到位时间。仅用编码器FK不能当实际末端精度证据。

建议初始目标：空中落点误差≤2mm、同向重复定位散布半径≤1mm；测量不确定度应明显小于门槛。最终阈值按指尖宽度、黑白键间隙与琴面高度确定，并在试验前冻结。将MIT与POS_VEL放在相同姿态、负载、速度和测量条件下比较。

空中定位通过后单独设计接触测试，规定下压深度、速度和力/电流上限。POS_VEL帧没有逐帧力矩字段，不以高刚度持续顶压琴键；必要时另行验证支持限流的控制策略。整曲演奏还需要按键时序验收，不能由静态精度直接推断。

## 5. 回退与停止

切换/保持/运动任一步失败，停止后续步骤，机械支撑并按已核实的当前模式失能。通信正常时逐轴回读失能；失败则标记STOP_UNCONFIRMED，依靠现场急停/断电，不声称已安全失能。

回退在失能及可靠支撑下进行：恢复该轴备份的原模式（原值1才回MIT），读回确认；恢复本轮明确修改的参数并核对差异。回退不自动使能。下一次MIT运行重新取得起点，以当前位置建立保持目标，不发送原轨迹终点。

不主动调用保存到Flash作为初次试验步骤；这不代表写寄存器必然易失。是否自动保存、是否需显式保存，以固件核实结果为准。验收后若决定长期采用模式2，再安排保存和断电重启后只读确认；严禁上电自动运动。
