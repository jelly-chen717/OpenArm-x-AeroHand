# 右J6保持偏差核查

## 结论与当前状态

已有记录证明右J6在J2动作前能够静态保持；本次异常是J2运动期间的持续偏移，**尚不能定性为新姿态下的静态保持能力不足**。用户最新现场观察：J2向外时可能扯到接线、线材拉紧。此观察与两关节同时增加的负载相符，应优先排查线束牵拉，尚未通过整理走线后的对照试验确认。

用户已确认右腕为原装夹爪。此前“没有观察到牵拉”的回复不能用于排除外力，后续现场观察以本段最新信息为准。

两次执行均已停止并读回14轴失能。最后只读参数核查仍为双臂7/7在线、总线0x0、14轴state=0。没有正在保持的控制进程，失能后关节可回落，不能把停止前的角度作为当前保持角度。

## 控制与只读参数核查

实际生效右J6为MIT模式、Kp60/Kd2、零前馈；MIT编码后的Kp约59.951。J2运动期间右J6目标位置保持不变，目标速度为0；每个周期仍发送右J6保持帧，反馈state=1。没有漏发保持、被失能或符号突然翻转的证据。

按编码后指令计算最后一帧PD输出约−2.344N·m，反馈−2.396N·m，相差约−0.051N·m；J2阶段平均绝对差约0.037N·m。说明控制器确实随偏差增加纠偏力矩，但该计算不能确定外部负载来源。

零速且无前馈时，Kp60在2°误差下的比例力矩只有约2.094N·m。因此位置保护可能先于3N·m反馈阈值触发。若未来独立静态试验确证需要2.4N·m，纯PD理论静差约2.29°；本轮2.396N·m是在运动中测得，不能直接当静载，也没有据此提高Kp。

已只读比较左右J6：MIT模式、减速比寄存器10、PMAX/VMAX/TMAX=12.5/30/10、过流参数、固件版本以及ASR/APR参数一致，仅Damp/Inertia略有差异。未发现右侧独有的模式或协议量程差异；未写任何参数。ASR/APR参数不替代本次MIT帧中的Kp/Kd。

## 模型能解释多少

使用真实14轴姿态重放，模型包含J6下游约1.202kg腕部和原装夹爪：

- 右J6模型重力需求从约0.252增至0.454N·m，仅增加约0.202N·m；实际反馈增加约1.97N·m。
- J2→J6惯性耦合系数约0.030kg·m²，按计划加速度估算耦合峰值约0.042N·m。实测速度微分估算含量化和异步误差，不能当物理上界。
- 右J2最后一帧模型重力约5.46N·m、动态总量约5.79N·m，反馈约18.21N·m。偏差不只出现在J6。

因此当前模型不能解释额外负载，也不能证明减慢J2即可解决。模型未包含真实线束牵拉、外部接触和全部机械摩擦；用户后续观察到的线材可能拉紧，是有现场依据的候选原因。
