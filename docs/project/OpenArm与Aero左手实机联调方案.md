# OpenArm 与 Aero 左手实机联调方案

2026-11-19 · 方案已整理，软件集成及现场验收待执行。

## 操作目标和现状

操作者在 OpenArm 实机调试页查看臂与手的实时反馈，移动机械臂、保持腕部姿态，并在同一会话中单步控制左手。首轮以空载、无接触的单指按抬作为验收动作，随后才进入琴键接触测试。现场先登记左手实际挂载的臂侧及腕部朝向，页面分别显示“机械臂侧”和“手型”。

现场钢琴为 C2–C7，左手食指原位为 B3（从 C2 起数第 14 个白键），右手食指原位为 C4（第 15 个白键）。单指对键记录同时填写音名和实琴白键号。[实琴编号与标定表](../../monitor-ui/README.md#实琴琴键与食指原位)

用户已确认左手机械安装。现有 [OpenArm 监视服务](../../apps/openarm_monitor.py) 提供 8092 实机和 8091 离线入口。[双手调试配置](../../openarm/tools/aero_score/config.json) 中左手仍为模拟，COM1 是占位，左手四指实机标定为空。右手 COM8 及其标定独立。11 月 19 日最近一次 C02 记录为 PCAN 枚举零路；现场恢复情况、驱动模式和新负载下的保持能力均待核验。

## 拟接入的操作链路

- **机械臂**沿用 8092 的预览、执行、到位保持、停止与失能回读。由现有服务独占 PCAN。先核实当前动作实际使能哪些轴，包括另一侧机械臂。
- **机械手**在同页增设“左手”面板，由独立串口线程持有现场辨认的 COM。复用 [AeroTransport](../../openarm/tools/aero_piano_test/core.py) 的读写与 [HandLink](../../openarm/tools/aero_score/core.py) 的线程归属模式。串口超时不能阻塞 CAN 控制周期。独立 GUI 完成标定后先释放串口，再由联合服务接管。
- 面板显示真机或模拟、端口、反馈时间、七路执行器位置及可用遥测。操作包括只读连接、选指微调、记录抬起位和按下位、单指按抬、停止。连接时只读；每次重连重新取七路基线。四指通道 3–6 按食指至小指核对，拇指三路保留实测基线。左手配置单独保存。
- 首轮协调顺序为“手指已抬起 → 臂运动 → 臂反馈到位且稳定 → 允许落指 → 抬指回读 → 允许下一次移臂”。臂到位与速度取本轮通过现场验证的判据，协议写入成功不能解除落指联锁。自由空间单指调试可在臂已稳定保持时独立进行。

## 分阶段操作与验收

| 阶段 | 操作 | 放行证据 |
|---|---|---|
| 1 安装和设备辨认 | 支撑腕部，检查固定件、供电、USB 和腕部线束余量，记录安装朝向、手掌与指尖外廓。逐一辨认左手串口与左右 PCAN，在机械臂失能状态完成 C02 只读盘点。 | 安装照片、端口与设备对应、实际轴模式和失能回读齐全。PCAN 未恢复时仍可在机械支撑下做手侧验证。 |
| 2 左手单机 | 用现有双手 GUI 选左手、取消左侧模拟、选择辨认出的端口，只连接左侧。取得稳定反馈后逐指小步核对方向，记录安装姿态下的抬起位和按下位。 | 每个已配置通道都有指名、目标、回读和目视动作记录；其他指与拇指无异常联动。 |
| 3 带手验臂 | 左手保持已核实的收拢或抬起姿态。在工作台上方留出净空，预览后执行一个经现场核定的小幅单轴往返。观察腕部负载、非指令轴偏移和全程线束。 | 保存带载起终姿态、跟踪误差、保持段、停止回读。旧 WEB03 左 J4/J6 偏移及原夹爪碰撞模型均需按实际安装复核。 |
| 4 联合页面离线验收 | 用替身 CAN 和模拟串口覆盖双在线、手串口占用、反馈过期、臂未到位、断线、停止与重连。 | 臂未稳定时落指被拒；任一链路异常后无新动作；停止记录区分两设备；重连后无旧命令重放。 |
| 5 实机联合验收 | 同一会话完成“臂小幅移位并保持 → 左食指空中按下 → 抬起 → 臂返回”。再验证人工停止。稳定后将同一序列用于单个琴键。 | 用同一时间轴核对臂到位、手指目标与回读、抬起后返程。琴键触发另用视频、音频或键盘 MIDI 记录对时。 |

## 停止与记录

联合停止先取消待发指令，同时请求两设备各自停止。臂侧沿用现有停止流程并记录失能是否回读；手侧立即停止发新帧，舵机可能继续保持末目标。正常收尾仅在通信健康、抬起位已标定且退让方向明确时主动抬指。若夹碰、通信中断或状态不明，禁止自动回位，将未确认设备显式标红；按现场电源与急停覆盖范围处理并支撑机械臂。重新连接后由操作者确认姿态再开始新动作。

每轮保存会话号、单调时间、实际端口与模式、手指标定版本、臂目标与实测、手目标与回读、故障发生和停止确认时间。建议归档到 logs/openarm/sync/ 下独立的当次会话目录。首轮通过标准为一次完整空中组合动作及一次停止验证均有双设备证据；触键、同时移臂落指及整曲演奏另行验收。
