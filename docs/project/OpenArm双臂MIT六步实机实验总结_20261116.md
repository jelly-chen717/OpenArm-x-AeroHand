# OpenArm双臂MIT六步实机实验总结

实验日期：2026年11月16日，时区Asia/Shanghai。对象为OpenArm V1左右机械臂，共14个关节电机，不含夹爪电机。控制方式为MIT位置与速度闭环控制。

**本次实验正常结束。六步双臂同步动作、逐步到位停留及最终14轴使能保持均通过本轮验收，最后由操作者现场断电或急停结束。** 六步实际完成时间23.784秒，末姿态已连续验证使能保持62.161秒。

## 实验目的与控制要求

验证左右同名关节能够按指定顺序同步运动，在目标位置附近稳定后停留1秒，再进入下一步；已执行关节持续保持目标，未执行关节保持本次起点，全部动作完成后14轴继续使能保持。重点检查关节方向、到位精度、阶段顺序、持续保持及反馈速度和力矩。

本次测试零点于21:49:33采集，经操作者明确确认。该零点只作为本次相对运动基准，未改变电机固件零位或全局标定。左臂使用CAN通道0x51，右臂使用0x52；启动前14轴在线、失能，MIT模式及协议量程检查通过。控制进程于21:51:16启动。

J5的“向外”采用镜像方向：左侧逆时针−88°，右侧顺时针+88°；第3步各自反向88°回本次零点。双臂同步表示两侧共用运动时间和阶段门控，不要求所有关节使用相同数值符号。J7的正方向是关节局部方向，其空间朝向随前序J5姿态改变。

## 测试方法与参数

六段规划移动时间依次为3.7、3.7、3.7、2.1、2.1、2.1秒，合计17.4秒；加六次到位后1秒停留，名义总时间23.4秒。轨迹采用静止到静止的五次插值，缓起缓停。J5/J7规划峰速44.59°/秒，J4为26.79°/秒，J1/J2为13.39°/秒。

每步均要求左右关节到位，全部14轴位置误差≤2°、速度反馈绝对值≤0.05rad/s，并连续保持1秒才推进。活动关节运行跟踪保护为5°；其他关节及最终保持误差阈值为2°。控制周期40ms，反馈年龄上限150ms，温度阈值50℃。MIT前馈力矩为0，Kp/Kd分别为J1/J2的300/5、J3的80/3、J4的200/3、J5～J7的60/2。

执行前完成152项离线软件回归；更新测试零点后再次进行6007点模型检查，未检测到模型接触，模型负载估算低于额定力矩。实机运行独立记录反馈，软件验证不代替实机验收。

本轮完成了左右臂J5向外旋转、J7翘起、J5回零、J4前屈、J1后摆及J2外展六步MIT控制验证。双侧方向与操作者最终要求一致，阶段到位、1秒停留和已执行关节持续保持均达标；最终14轴使能保持已得到62.161秒实测验证。本次实验验收通过并正常结束。

## 后续实验规划原则

后续按操作者明确的要求安排：**以机器人中轴为中心规划左右镜像动作；本次测试零点放在规划完成后、执行前的最后准备阶段采集和确认。** 先完成方向、顺序、幅度、速度、力矩及时间规划，再固定现场起点，可减少准备期间姿态变化造成的重复采零。

镜像面为机器人中轴所在的前后竖直平面，即当前坐标系的XZ平面（Y=0；+X向前、+Y向左、+Z向上）。目标是左右机械臂的实际姿态和运动路径互为镜像。当前逻辑坐标约定下，两侧关节角的对应关系为：

| 关节 | 左右镜像时的角度关系 |
| --- | --- |
| J1、J2、J4、J6、J7 | 同号、同角度 |
| J3、J5 | 反号、同幅度 |

上述关系适用于当前映射`hardware-unified-forward-inward-v2-20261116`。例如J5向外转88°应写为左−88°、右+88°；向里返回时，增量为左+88°、右−88°，终点为各自本次零点0°。第3步的实际行程仍是88°，“终点0°”不表示“行程0°”。方向描述需注明观察基准，关节局部正向在前序关节转动后不一定仍对应世界坐标中的同一方向。

严格镜像还要求双臂安装与起始姿态对称。将任意左右姿态分别记为0°，只能建立两个相对运动基准，不能消除原有的姿态差；仅施加镜像增量也不能据此证明全程几何镜像。本次已验证规定动作和方向，未单独量化全程空间镜像误差，后续应把镜像起点和路径对应纳入规划核对。

后续采用以下顺序：

1. **确定镜像动作。** 先用向前、向后、向里、向外表达物理意图，再分别填写左右关节角；回零同时注明终点和本段行程。
2. **完成软件与运动规划。** 确定顺序、两侧共用的移动时长、速度与加速度、力矩估算、到位后停留及保持策略，完成离线预演和初步限幅检查。
3. **最后确认起点并采集测试零点。** 现场接线、支撑和姿态调整完成后，核对左右起姿是否满足镜像要求，再采集14轴实际位置并记录基准时间。这里指本次相对测试零点；电机固件零位和全局标定属于另行明确范围的工作。
4. **按最终零点复算并提交审核表。** 将相对动作换算为绝对目标，复核整条路径的机械限位、接触、速度和力矩；表中列出左右目标、方向、移动时间、速度、力矩及停留时间。经操作者授权、执行前起点复核通过后运行；若起点变化，处理变化后重新校核。

本次六步实验保持“验收通过、正常结束”的结论。以上为后续规划约定，不代表已实施新的零点标定或新的实机运动。
