## 第二部分 常见参数

### 1. 串口与电机对象

```python
serial_device = serial.Serial('COM5', 921600, timeout=0.5)
Motor1 = Motor(DM_Motor_Type.DM4310, 0x01, 0x11)
```

| 参数 | 含义 | 示例说明 |
|---|---|---|
| 串口名称 | 连接适配器的串口 | `COM5` 仅为示例，Windows 中按设备管理器确认；Linux 常见 `/dev/ttyACM0` |
| 波特率 | 串口通信速率 | 示例为 `921600`，需与适配器配置匹配 |
| `timeout` | 串口读取超时时间 | `0.5` 表示 0.5 秒 |
| `MotorType` | 电机型号 | 示例为 `DM_Motor_Type.DM4310` |
| `SlaveID` | 电机 CAN ID | 示例为 `0x01`，十进制为 1 |
| `MasterID` | 主机 ID，关联电机反馈报文 | 示例为 `0x11`，十进制为 17；教程建议避免设为 0 |

### 2. MIT 控制参数

```python
MotorControl1.controlMIT(Motor1, kp, kd, q, dq, tau)
```

| 参数 | 中文含义 | 常见单位或理解 |
|---|---|---|
| `Motor1` | 电机对象 | 指定操作哪台电机 |
| `kp` | 位置比例增益、位置刚度 | 通常为 N·m/rad，位置偏差越大，纠正力矩越大 |
| `kd` | 速度增益、阻尼系数 | 通常为 N·m·s/rad，根据速度偏差产生纠正力矩 |
| `q` | 目标位置 | 通常为 rad |
| `dq` | 目标速度 | 通常为 rad/s |
| `tau` | 前馈力矩 | 通常为 N·m，可用于重力补偿等 |

常用控制关系为：

```text
输出力矩 = kp × (目标位置 − 当前位置)
         + kd × (目标速度 − 当前速度)
         + 前馈力矩
```

当前 SDK 将 `kp` 按 0～500、`kd` 按 0～5 的范围编码。实际适用增益、力矩输出和限制需结合电机型号与负载确认。

### 3. 其他控制模式参数

| 函数 | 参数顺序 | 作用 |
|---|---|---|
| `control_Pos_Vel()` | 电机对象、`P_desired`、`V_desired` | 设置目标位置和速度参数 |
| `control_Vel()` | 电机对象、`Vel_desired` | 设置目标速度 |
| `control_pos_force()` | 电机对象、`Pos_des`、`Vel_des`、`i_des` | 力位混合控制 |

`control_Pos_Vel()` 的位置和速度通常采用 rad、rad/s。当前函数注释未明确写出单位，速度参数的具体控制含义需查对应型号手册。

`control_pos_force()` 中的参数需要特别区分：

| 参数 | 含义 | 当前代码注释中的缩放关系 |
|---|---|---|
| `Pos_des` | 目标位置 | 单位 rad |
| `Vel_des` | 速度参数 | 速度按 rad/s 放大 100 倍传入，例如 `1000` 对应 10 rad/s |
| `i_des` | 电流标幺值 | 实际电流与最大电流之比放大 10000 倍，例如 `100` 对应最大电流的 1% |

教程给出的速度、电流参数输入范围均为 0～10000，最终支持范围及最大电流定义以对应电机手册为准。

### 4. 常见内部参数

通过 `DM_variable.参数名` 指定要访问的参数。

| 参数名 | 中文含义 | 理解要点 |
|---|---|---|
| `PMAX` | MIT 位置映射上限 | 通常按 −PMAX～+PMAX 编码、解码位置，单位 rad |
| `VMAX` | MIT 速度映射上限 | 通常按 −VMAX～+VMAX 编码、解码速度，单位 rad/s |
| `TMAX` | MIT 力矩映射上限 | 通常按 −TMAX～+TMAX 编码、解码力矩，单位 N·m |
| `MST_ID` | 主机 ID | 电机反馈报文使用的 CAN ID |
| `ESC_ID` | 电机侧 ID | 电机接收控制报文的基础 ID，具体规则见协议 |
| `CTRL_MODE` | 控制模式 | MIT、位置速度、速度等模式 |
| `Gr` | 减速比 | 具体定义与参数值以对应型号手册为准 |
| `sub_ver` | 子版本号 | 具体版本含义以对应固件说明为准 |
| `hw_ver` | 硬件版本 | 硬件版本信息 |
| `sw_ver` | 软件版本 | 软件或固件版本信息 |
| `TIMEOUT` | 超时参数 | 单位、取值和触发后的行为需查手册 |
| `KP_APR` | 位置环比例增益 | APR 通常指位置调节器，具体定义与范围需查手册 |
| `KI_APR` | 位置环积分增益 | 同上 |
| `KP_ASR` | 速度环比例增益 | ASR 通常指速度调节器，具体定义与范围需查手册 |
| `KI_ASR` | 速度环积分增益 | 同上 |

PMAX、VMAX、TMAX 用于通信数值映射。机械限位、实际速度和力矩能力还需要结合设备规格及限制参数判断。当前 `DM_variable` 附近对这三项的中文注释存在歧义，查阅时需结合协议手册核对。

### 5. 反馈状态与参数操作

| 名称 | 含义 |
|---|---|
| `state_q` / `getPosition()` | 对象保存的位置反馈 |
| `state_dq` / `getVelocity()` | 对象保存的速度反馈 |
| `state_tau` / `getTorque()` | 对象保存的力矩反馈 |
| `state_err` / `getError()` | 对象保存的错误状态 |
| `read_motor_param(motor, RID)` | 通过通信读取指定内部参数 |
| `getParam(RID)` | 从对象缓存中取出已读取的参数 |
| `change_motor_param(motor, RID, value)` | 修改支持写入的参数 |
| `save_motor_param(motor)` | 将支持持久化的参数保存到 Flash，函数内部会执行失能 |

`RID` 表示要访问的参数编号，例如 `DM_variable.PMAX`。状态获取方法返回最近一次接收并保存的反馈，刚创建对象时的零值属于初始化数据。配置修改后需要长期保留时，再按手册要求保存到 Flash。
